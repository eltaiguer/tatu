# Tatu domain context

Tatu's UI is Spanish (Rioplatense) and its code is English. This page maps one
to the other and defines the project-specific terms, so new code and new copy
use the names that already exist. Definitions describe current behaviour; if
the code changes, update this page in the same PR.
How the pieces fit together (data flow, categorizer precedence) is in
[`architecture.md`](architecture.md).

The brand is written **Tatú** in UI strings (page titles are
`Resumen · Tatú`) and **Tatu** in the repo.

## Views

| View (UI label) | `View` id      | URL path         | What it is                                                                                      |
| --------------- | -------------- | ---------------- | ----------------------------------------------------------------------------------------------- |
| Resumen         | `overview`     | `/`              | Dashboard: "Qué cambió", account cards, "Este mes", category list, charts, "Mayores comercios". |
| Transacciones   | `transactions` | `/transacciones` | Filterable transaction table with edit, split, delete and bulk actions.                         |
| Insights        | `insights`     | `/insights`      | AI-written spending insights over the whole history.                                            |
| Categorías      | `categories`   | `/categorias`    | Page title "Categorías y reglas": category grid plus "Reglas de auto-categorización".           |
| Configuración   | `settings`     | `/configuracion` | Theme, "Moneda principal", "Tipo de cambio", AI key, data management.                           |
| Importar        | (not a view)   | (none)           | Sidebar button that opens the CSV import dialog (`ImportCSV`). Import is a dialog, not a route. |

`View` lives in `AppSidebar.tsx`; paths and page titles live in
`src/routes.ts` (`pathForView`, `viewFromPath`, `titleForView`). Unknown paths
fall back to Resumen.

| Transaction               | One row of a bank or card statement, normalized: positive `amount`, a `type` (`debit` = money out, `credit` = money in), a native `currency` and a `source`.                                                                                                                                                                                                                                                                                                          | `Transaction`, `TransactionType`, `TransactionSource`                                                                                   | "Transacciones"; prose and empty states also say "movimientos"                                                               |

## Santander statement formats

The importer auto-detects three CSV exports (`detectFileType`):

- **Credit card** (`credit_card`): detected by `tarjeta de cr` or by both
  `Tipo de producto` and `Fecha de corte` in the first 10 lines. Rows start two
  lines after the `Movimientos` marker. Amounts use `1.234,56`. A row is in USD
  when its dólares column is non-zero, otherwise UYU; negative amounts are
  credits (payments).
- **Bank account, USD or UYU** (`bank_account_usd` / `bank_account_uyu`):
  detected by `Moneda,USD` or `Moneda,UYU`. Rows start after the
  `Fecha,Referencia,…` header. The description is `concepto` and `descripcion`
  joined. A filled `debito` column means a debit; otherwise it is a credit.

A value that does not parse as a number stops the import with the row number
(`Fila N: …`) rather than turning into `NaN`. A file that matches none of the
three formats ("No reconocemos este archivo…") or is empty ("El archivo está
vacío.") is rejected the same way. Parser errors are `UserFacingError`s; the
`.csv` extension check ignores case.

## UI copy guide

### Register: Rioplatense voseo

Address the user as **vos**. Imperatives drop the final `-r` and stress the
last syllable (with an accent); present tense ends in `-ás` / `-és` / `-ís`.
Never use tuteo (`Arrastra`, `Elige`, `Importa`) or usted (`Arrastre`,
`Elija`).

Real strings from `src/`:

| Do (voseo, from the code)                                         | Don't                                           | Where                      |
| ----------------------------------------------------------------- | ----------------------------------------------- | -------------------------- |
| "Arrastrá tu archivo CSV aquí"                                    | "Arrastra tu archivo…" / "Arrastre su archivo…" | `ImportCSV.tsx`            |
| "Elegí una categoría."                                            | "Elige una categoría."                          | `transaction-mutations.ts` |
| "Importá tu primer extracto de Santander…"                        | "Importa tu primer extracto…"                   | `Onboarding.tsx`           |
| "Probá ampliar el rango o limpiarlos."                            | "Prueba ampliar el rango…"                      | `TransactionTable.tsx`     |
| "Revisá tu casilla y confirmá tu email."                          | "Revisa tu casilla y confirma tu email."        | `auth-errors.ts`           |
| "Subí el extracto de tu tarjeta o caja de ahorro Santander."      | "Sube el extracto…"                             | `Onboarding.tsx`           |
| "La transacción ya no existe. Recargá para ver el estado actual." | "Recarga para ver…"                             | `transaction-mutations.ts` |
| "Tu sesión terminó. Iniciá sesión de nuevo para guardar cambios." | "Inicia sesión…"                                | `repository.ts`            |
| "Seleccioná la cuenta o tarjeta que querés exportar"              | "Selecciona la cuenta… que quieres exportar"    | `ImportCSV.tsx`            |
| "Tipo de cambio que ingresaste vos · editar"                      | "…que ingresaste tú…"                           | `FxChip.tsx`               |

With an enclitic pronoun the stress moves and the accent goes away:
"seleccionalo" (`Onboarding.tsx`), not "seleccionálo" or "selecciónalo".

### Tone

- Short and direct; say what happened and what to do next ("No se pudo
  iniciar la importación. Intentá de nuevo.").
- Reassure when data is safe ("…tus datos están a salvo.").
- Messages meant for the user are Spanish and go through `UserFacingError`.

### Capitalisation

Sentence case everywhere: headings, buttons, labels, menu items. Only the first
word and proper nouns are capitalised: "Qué cambió", "Mayores comercios",
"Ignorar en totales", "Moneda principal", "Dividir transacción". Sidebar group
labels ("General", "Gestión") are uppercased by CSS, not in the string.

### Money

- Use `formatCurrency(amount, currency)`: symbol, a space, then the `es-UY`
  number with 2 decimals: `US$ 1.234,56`, `$U 1.234.567,50`. Dot for
  thousands, comma for decimals. It prints the absolute value; show the sign
  or direction separately.
- Chart axis ticks on Resumen use `formatCurrencyShort`: `US$ 1k`, `$U 1.2M`.
- Symbols are always `US$` (dollars) and `$U` (pesos), never `USD`/`UYU` in
  prose. The UYU account card is "Cuenta $U"; the USD one is "Cuenta USD".
- A converted amount next to a native one is marked with `≈`.
- Amounts use the `.amt` class or `font-mono` + `tabular-nums`.

### Dates

- `formatDate`: `05/03/2026` (`es-UY`, day first).
- `formatDateCompact`: `5 mar.`.
- Month names in copy are lowercase Spanish ("Qué cambió en marzo").
